Misi & Visi

1. Pengenalan & Misi SocialHub

SocialHub dibina khusus untuk membantu usahawan digital, content creator, ejen hartanah, dan ejen affiliate di Malaysia menjimatkan masa dalam merancang, menjana, dan menjadualkan copywriting di Threads secara automatik.

Platform ini membolehkan anda memfokuskan kepada kualiti produk/servis manakala enjin AI kami menguruskan penghasilan bebenang (Thread Storm) yang berimpak tinggi mengikut tone penulisan manusia sebenar.

⚡ Pantas & Lancar

Generate copywriting unik, bina CTA bersesuaian, dan jadualkan post terus ke Threads dalam masa kurang 5 saat.

🧠 AI Sentiasa Pintar

Enjin AI dilatih dengan cara copywriting Threads tempatan yang tidak berbunyi formal atau skema.

Mula

2. Setup Pertama Kali (First-Time Login)

Sebelum mula menjana copywriting, anda perlu menyambungkan akaun media sosial Threads anda ke dalam workspace.

  • Langkah 2.1: Log masuk ke Dashboard SocialHub anda dan navigasi ke bahagian Accounts di menu tepi.
  • Langkah 2.2: Klik butang Connect Accounts dan pilih platform Threads.
  • Langkah 2.3: Sahkan kebenaran (authorize) akaun anda dengan meluluskan akses `threads_basic` dan `threads_manage_insights` agar sistem boleh menyiarkan post serta membaca data analytics akaun anda.

Nota Keselamatan: Token akaun media sosial anda disulitkan secara tegar (encrypted) di dalam pangkalan data kami menggunakan kunci penyulitan khusus untuk keselamatan maksimum akaun anda.

Kreatif

3. Penjana Kapsyen AI (AI Generator)

Modul AI Generator membolehkan anda menjana content Threads berkualiti tinggi berdasarkan deskripsi ringkas sahaja. Terdapat tiga tab utama:

  • Single Post / Threads Creator: Masukkan jenis bisnes, penerangan produk, sasaran audiens, dan biarkan AI menjana post bertali-arus.
  • Presets Mode: Pintasan mudah untuk menjana zikir/selawat harian, ucapan salam pagi (morning greetings), petikan motivasi, atau check-in soalan santai untuk interaksi audiens.
  • Tone of Voice: Sangat disyorkan menggunakan tone "Ultra-Realistic Malay" untuk menghasilkan gaya rojak bahasa Malaysia/Inggeris natural seperti yang ditulis oleh manusia sebenar di Threads (bebas dari ayat formal bot iklan).
Automatik

4. Bulk Auto-Schedule & Auto-Staggering

SocialHub mempunyai modul URL Auto-Post pintar yang memudahkan anda membuat jadual kandungan secara pukal dengan pantas.

  • Auto-Scraping: Cuma masukkan link pautan jualan (seperti iklan hartanah atau link affiliate). Sistem akan melawat halaman tersebut, mengumpul maklumat spesifik produk (tajuk, penerangan, gambar), lalu menghantarnya kepada AI.
  • Pemendek Link Automatik (`nakcuba.my`): Sistem akan menukar link panjang affiliate atau WhatsApp anda kepada link pendek jenama tempatan `https://nakcuba.my/l/[kod]` secara automatik bagi mengesan statistik klik.
  • Auto-Staggering (Langsung Jadual): Apabila butang Schedule Post diklik, sistem akan terus menjadualkan post tersebut secara automatik dengan selang masa 15 minit selepas posting berjadual terakhir Zaim. Tiada lagi keperluan popup modal manual!

5. Pelan Langganan, Had Workspace & Set API Key Sendiri

SocialHub mengguna pakai model langganan per-Workspace (bukan per-Account). Ini bermakna, caj langganan dikenakan bagi setiap projek/ruang kerja yang anda naiktaraf (upgrade). Sebarang workspace baru yang dicipta akan bermula dengan pelan Free secara lalai.

Mulai v1.3.0, platform kami telah dilengkapi dengan Global API Key yang dipasang secara selamat pada server backend. Ini bermakna anda tidak perlu lagi memasukkan API Key anda sendiri untuk mula menggunakan model premium seperti Gemini 3.6 Flash, GPT-4o atau GPT-5.5 / Pro. Anda hanya perlu pilih model kegemaran anda di Settings dan mula menjana!

Bagaimanapun, jika anda mahu menggunakan API Key peribadi anda sendiri bagi membuang had kredit penjanaan AI (bypass limit), anda masih boleh berbuat demikian secara PERCUMA melalui ruangan AI API Key di halaman Settings.

Cara Dapatkan API Key Gemini/OpenAI Percuma (BYOK):

  1. Layari laman web Google AI Studio untuk Gemini Key, atau OpenAI Platform untuk OpenAI Key.
  2. Log masuk menggunakan akaun anda.
  3. Dapatkan/Jana API Key baru anda.
  4. Pergi ke dashboard SocialHub, navigasi ke Settings > Workspace Settings.
  5. Tampal kod tersebut ke dalam ruangan **AI API Key** dan klik **Save AI Settings**.

Sebab Utama Menggunakan Gemini 3.6 Flash & GPT-5.5:
• Gemini 3.6 Flash: Model terbaik untuk keseimbangan kos & kelajuan, menyokong data scraping yang besar, serta menjana gaya penulisan rojak Malaysia yang sangat bersahaja.
• GPT-5.5 / Pro: Model berasaskan Reasoning (penaakulan mendalam) yang sangat pintar untuk menyusun bebenang post (Thread Storm) yang logik, tersusun, dan mempunyai kadar conversion yang tinggi.

Analytics

6. Graf Followers & Analitis Insights

Tab Analytics membekalkan maklumat terperinci mengenai prestasi akaun Threads anda secara visual:

  • Followers Growth (Graf Pertumbuhan): Menunjukkan perkembangan jumlah followers secara harian. Jika Zaim baru sahaja menyambungkan akaun, data akan mula diplot secara automatik sebaik sahaja log data pertama direkodkan.
  • Cron Sync (Penyelarasan Automatik): Sistem backend kami menjalankan proses penyelarasan di latar belakang secara berkala (cron job berjalan setiap minit untuk queue posting, dan setiap 4 jam untuk mengemas kini insights posts & followers count akaun anda dari server Meta).
  • Threads Insights API: SocialHub mematuhi garis panduan Meta rasmi dengan menggunakan Threads Insights API yang selamat untuk menarik data statistik posting (views, likes, replies, reposts) tanpa menjejaskan privasi akaun.
